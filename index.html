Dewy Bank Workshop Setup

Securing AI agents · Hands-on workshop

Set up Dewy Bank

By the end you'll have the workshop's three stations deployed to your own Workato workspace, and the bank app's chat talking to their six MCP servers. Do it by hand, or let a coding agent run the terminal work while you handle the steps only a person can do.

Hand this to your agent

Open your agent in the folder where you want the repo, paste the prompt below, and follow along here. Your agent runs the terminal steps and stops whenever it needs you. When it does, do the step on this page, then reply done.

    PHASE 1Get the tools
    
    
    Everything in this phase runs in a terminal.
    

    
    
      
    1
    
      
    
        
    Check your laptop
    
        
    You need Python 3 and Git. Both commands should print a version.
    
        
    Your agent checks for Python 3 and Git and tells you if either is missing.

git --version
    
      
    
    
    

    
    
      
    2
    
      
    
        
    Install the wk CLI and recipe linter
    
        
    wk pushes the workshop's recipes and connectors to Workato. On a Mac, install both with Homebrew:
    
        
    Your agent installs wk and the linter with Homebrew. If Homebrew isn't installed, it stops and asks you to install it.
    
        
    brew install workato-devs/tap/wk workato-devs/tap/recipe-lint
wk plugins install recipe-lint
wk version
    
        
    On Windows, see the Workato Labs install guide for the Scoop commands. The rest of this guide hasn't been tested on Windows yet, so ask a facilitator if you get stuck.

    Clone it with Git rather than downloading a ZIP. The deploy script uses Git to put files back the way they were after it runs.

    PHASE 3Let the CLI into your workspace
    
    
    You create a token in Workato and save it on your laptop. The CLI and the deploy script read it from there.
    

    
    
      
    6
    
      
    
        
    Create an API client
    
        
      
          
    1. In Workato, go to Workspace admin → API clients → Client roles and create a role.
      2. 
          
    2. Go to Workspace admin → API clients, create a client, and give it that role and access to your workspace.
      3. 
          
    3. Copy the token. It starts with wrk, and Workato shows it only once.
      4. 
        
    
        
    Give the role these permissions. They're what the workshop's scripts use, laid out the way the Client role editor shows them:
    
        
    
          
    TabSectionPermissions

    PHASE 4Deploy to Workato
    
    
    One script pushes the connectors, the three stations and their MCP servers. It pauses twice for you.
    

    
    
      
    9
    
      
    
        
    Run the deploy script
    
        
    python3 scripts/deploy_workato.py -p dewy
    
        
    It points the connectors at your bank, pushes them to your workspace, then stops and prints a link to your connections. Keep this terminal open.
    
        
    Your agent runs the deploy script. An agent can't press Enter at the script's pauses, so the script stops at each one instead. Your agent hands the pause to you, and runs the next part once you reply done.
    
      
    
    
    

    
    
      
    10
    
      
    
        
    Connect Workato to the bank
    
        
    Open the connections link the script printed (in Workato: Connections) and connect both:
    
        
      
          
    • Dewy Bank Customer API: your Dewy Bank email and password from step 4. Use your bank login, not your Workato one.
      • 
          
    • Dewy Bank Support API: the support code is already filled in, so just choose Connect.
      • 
        
    
        
    Wait until both show Connected.
    
        
    Then press Enter in the terminal. The script pushes the three stations, starts their recipes and creates six MCP servers. This takes a few minutes. It pauses again when it needs the servers' URLs.
    
        
    Then reply done. Your agent runs the script again. It pushes the three stations, starts their recipes and creates six MCP servers, which takes a few minutes.
    
      
    
    
    

    
    
      
    11
    
      
    
        
    Copy your six MCP server URLs
    
        
    Each MCP server sits in its Dewy Bank Station folder in Workato. For each one, open it, generate a token, copy its URL with the token, and paste it into .env on its line:
    
        
    
          
    LineMCP server
    
          
            
    A1=StationA1
    
            
    A2=StationA2
    
            
    B1=StationB1
    
            
    B2=StationB2
    
            
    C1=StationC1
    
            
    C2=StationC2 Customer
    
              
        
    
        
    Each URL looks like https://…apim.mcp.trial.workato.com/?wkt_token=…. Replace the whole <paste …> placeholder.
    
        
    These URLs are credentials. Anyone who has one can act as you in the bank through that server, so keep them out of chats and screenshots.
    
        
    Save .env, then press Enter in the terminal. The script prints your chat config and saves it to mcp_conf.json.
    
        
    Save .env, then reply done. Your agent checks all six are set and writes your chat config to mcp_conf.json without displaying it.

    If something goes wrong
    
  
    
    wk profile "…" is not connected
    
    The CLI isn't signed in. Do step 8 again, and check the profile name matches the one in your command.
    
  
    
  
    
    Running non-interactively; cannot wait for connections to be authenticated
    
    Expected when an agent runs the script. Connect both connections (step 10), then run the deploy script again.
    
  
    
  
    
    Connections still not authenticated after re-check
    
    Open Connections in Workato and check both say Connected. For the Customer API, use your Dewy Bank login, not your Workato one. Then run the deploy script again.
    
  
    
  
    
    expected one folder named "Dewy Bank Station …" or no skill …; push the project first
    
    The stations didn't finish pushing. Run the deploy script again. If it fails the same way twice, ask a facilitator.
    
  
    
  
    
    Dewy answers, but can't see your accounts
    
    Check each line in .env holds a full URL ending in ?wkt_token=…. Then rebuild the config with python3 scripts/setup_mcp_servers.py -p dewy, press Enter when it asks, and paste the new mcp_conf.json into the bank app.
    
  
    
  
    Dewy Bank is deliberately insecure. It's a mock bank built for this workshop, holding no real money or customer data.
